# PULSE FIT — Fitness Club Landing Page

Адаптивный одностраничный сайт (landing page) для современного фитнес-клуба в тёмной теме с акцентным салатовым цветом.

## Возможности

- Mobile-first вёрстка: смартфоны, планшеты, ПК
- Шапка с плавным скроллом к секциям, подсветкой активного пункта и мобильным «гамбургер»-меню
- Hero-экран с анимированной статистикой
- Секции: преимущества, направления тренировок (hover-анимации), тарифы, тренеры, контакты с картой
- Модальное окно записи: закрытие по крестику, клику вне окна и Esc, focus trap
- Форма с маской телефона, валидацией полей и имитацией отправки (`e.preventDefault()`)
- Анимации появления блоков при прокрутке, учёт `prefers-reduced-motion`

## Стек

Чистый HTML5 + CSS3 + Vanilla JavaScript в одном файле `index.html`.
Подключаются только Google Fonts (Montserrat, Inter) и Font Awesome через CDN. Фото — Unsplash.

## Запуск

Сборка не нужна.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/spartak17mc-blip/fitness-landing.git
   ```
2. Откройте `index.html` в браузере.

Или запустите локальный сервер:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000.

## Подключение реальной отправки заявок

Сейчас отправка формы имитируется. Чтобы отправлять заявки на сервер, замените `setTimeout` в блоке «8. Имитация отправки» скрипта на `fetch('/api/lead', { method: 'POST', body: JSON.stringify(data) })`.
